# Chapter 3: Why Sequence Models Fail

*RNNs were slow because they were sequential. So why not just swap in a different architecture that's parallel — like a CNN? This chapter is about why that almost worked, and why "almost" wasn't good enough.*

---

## 1. The Goal

Everything so far has been in service of one goal:

> **Reduce sequential computation, so the model can actually use a GPU's parallel power.**

RNNs fail this goal outright — one step must finish before the next can begin. So before the Transformer, researchers tried a different building block entirely: the **CNN**.

Architectures like **Extended Neural GPU**, **ByteNet**, and **ConvS2S** all replaced RNNs with CNNs. To be clear — these are *model architectures*, not literal graphics chips; they simply use convolutional layers as their core building block instead of recurrent ones.

---

## 2. What Is a CNN?

A **Convolutional Neural Network** was originally built for images, but it adapts well to text too.

Instead of reading one word at a time like an RNN, a CNN slides a small **window (kernel)** across the sentence, looking at a few words together at once:

```
"The cat sat on the mat"

Window 1: [The, cat, sat]
Window 2:      [cat, sat, on]
Window 3:           [sat, on, the]
Window 4:                [on, the, mat]
```

Because each window is processed independently, all of them can be computed **at the same time** — this is what makes CNNs parallelizable, unlike RNNs.

| Feature | RNN | CNN |
|---|---|---|
| Processing style | One step at a time | Many windows at once |
| Parallelizable | No | Yes |
| Long-range connections | Travels through hidden states | Needs many stacked layers |
| Originally designed for | Sequences | Images (adapted for text) |

So far, CNNs sound like a clean win. But look closely at the windows above: **"The"** (position 1) and **"mat"** (position 6) never appear in the same window. A single convolution layer simply cannot connect words that are farther apart than its kernel size. This is the **distance problem** — and it's the reason CNNs alone weren't enough.

---

## 3. How Bad Is the Distance Problem?

To let two distant words influence each other, you have to **stack multiple CNN layers**, letting the "field of view" grow layer by layer. How many layers you need depends on the type of convolution:

### Standard convolution — linear growth

With a kernel size `k`, connecting word 1 to word `n` takes roughly `n/k` stacked layers.

```
Sequence length = 100, kernel size = 3
Layers needed ≈ 100 / 3 ≈ 33
```

Growth = **O(n)** — this is what ConvS2S uses. Connecting word 1 and word 50 realistically takes about 50 layers of depth.

### Dilated convolution — logarithmic growth

ByteNet improves on this by skipping positions in the kernel (e.g., looking at positions 1, 3, 5 instead of 1, 2, 3), so the "field of view" grows exponentially with depth instead of linearly.

```
Sequence length = 100, kernel size = 3
Layers needed ≈ log₃(100) ≈ 5–6
```

Growth = **O(logₖ n)** — a real improvement, but distant words still need to pass through several layers before they can "talk" to each other.

### Self-attention — constant, in one step

The Transformer skips the stacking problem entirely. Every word can directly attend to every other word **in a single layer**:

```
"The" ↕ "mat"      →  one direct connection, no intermediate layers
```

Growth = **O(1)** — the distance between two words in the sentence no longer matters at all.

---

## 4. Comparing the Architectures Formally

The original paper backs this up with three concrete metrics, comparing self-attention against recurrent and convolutional layers. Here, `n` is sequence length, `d` is the model's dimension (512 in the base Transformer), `k` is convolution kernel size, and `r` is the window size used in a *restricted* form of self-attention.

| Layer Type | Complexity per Layer | Sequential Operations | Max Path Length |
|---|---|---|---|
| Self-Attention | O(n² · d) | O(1) | O(1) |
| Recurrent | O(n · d²) | O(n) | O(n) |
| Convolutional | O(k · n · d²) | O(1) | O(logₖ n) |
| Self-Attention (restricted) | O(r · n · d) | O(1) | O(n/r) |

Three things stand out:

**Complexity per layer.** Self-attention (`n²·d`) is actually *cheaper* than a recurrent layer (`n·d²`) whenever `n < d` — and for most sentences, that's true. A typical sentence has 10–50 words, while `d` = 512, so `n < d` holds comfortably in practice.

**Sequential operations.** Self-attention and CNNs both score O(1) here — meaning the whole sequence can be computed at once, with nothing waiting in line. RNNs score O(n): word 4 genuinely cannot be processed until words 1–3 are done.

**Max path length.** This is where self-attention pulls decisively ahead. It's the only architecture with a *constant* path length, O(1), regardless of how long the sentence is.

---

## 5. Why Path Length Actually Matters

Path length isn't an abstract number — it directly affects how well a model can resolve long-range dependencies. Consider:

> "The trophy didn't fit in the bag because it was too big."

To correctly resolve what **"it"** refers to (the trophy, not the bag), the model has to connect two words that sit several positions apart. The shorter the path between them, the easier that connection is to learn — and the less that signal degrades along the way, similar to how information blurs the more hops it passes through in a game of telephone.

- An **RNN** has to carry that information through every hidden state in between.
- A **CNN** has to pass it up through several stacked layers.
- **Self-attention** connects the two words directly, in one step, regardless of the gap between them.

---

## 6. But What About the *Best-Case* CNN?

To be fair to CNNs, the paper also considers their most efficient form: **separable convolutions**, which split the computation into two cheaper stages (spatial processing, then channel mixing). This drops the complexity from `O(k·n·d²)` down to `O(k·n·d + n·d²)`.

Push this further and set the kernel size `k = n` (the largest possible window) — now the complexity becomes `O(n²·d + n·d²)`.

That's *identical* to the combined cost of self-attention plus its accompanying feed-forward layer:

| Property | Separable CNN (k = n) | Self-Attention + FFN |
|---|---|---|
| Complexity | O(n²d + nd²) | O(n²d + nd²) |
| Sequential Operations | O(1) | O(1) |
| Max Path Length | O(logₖ n) | **O(1)** |
| Interpretability | Low | High |

Even at its theoretical best, a CNN still needs multiple layers before two distant words can connect — its path length stays at O(logₖ n). Self-attention keeps its O(1) advantage no matter what.

---

## 7. A Bonus: Interpretability

Self-attention has a side benefit the paper points out explicitly: it produces attention weights that show, in plain numbers, which words influenced a given prediction.

```
Attention("it")
cat     → 0.65
tired   → 0.20
mat     → 0.10
sat     → 0.05
```

Compare that to an RNN's hidden state (a dense, opaque vector) or a CNN's feature map (local patterns, but no explicit word-to-word relationships) — attention gives you a far more transparent window into the model's reasoning.

---

## 8. The Hidden Cost of Attention

None of this comes for free. Self-attention introduces its own problem: **reduced effective resolution**.

When a word attends to every other word, it computes a *weighted average* of all that information — everything gets blended together. Picture the difference between one clear photo and a blend of fifty overlapping photos: the overall shape survives, but the sharp, specific details start to wash out.

The fix, which we'll cover in the next chapter, is **multi-head attention** — running several attention "cameras" in parallel, each capturing a different angle (grammar, meaning, position), then combining them into one sharp, rich picture instead of one blurry one.

---

## 9. The Story So Far

- **RNNs** → sequential, slow, cannot be parallelized
- **CNNs** → parallel, but still need multiple stacked layers to connect distant words
- **Self-attention** → direct connections between any two words, O(1) path length, fully parallel
- **New problem** → blending information across all words can blur fine detail
- **Coming next** → multi-head attention restores that lost clarity

> **One-line insight:** Self-attention solved the distance problem that RNNs and CNNs couldn't — but it traded that win for a blurriness problem, which multi-head attention was built to fix.
