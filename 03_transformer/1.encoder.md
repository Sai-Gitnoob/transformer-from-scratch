# Transformer Encoder Architecture

## 1. Overview

The Transformer encoder is composed of **N = 6 identical layers stacked sequentially**.  
Each layer (also called an *encoder block*) has the same internal structure but learns different representations during training.

Each encoder block contains two main sublayers:

1. **Multi-Head Self-Attention**
2. **Feed Forward Neural Network**

---

## 2. High-Level Flow

```
Input
↓
[Encoder Block 1]
↓
[Encoder Block 2]
↓
...
↓
[Encoder Block 6]
↓
Final Encoder Output (z)

```
---

Each block refines the representation produced by the previous one.

---

## 3. Structure of a Single Encoder Block

Each encoder block consists of two sublayers, and **each sublayer is wrapped with:**

- A **residual connection**
- Followed by **layer normalization**

### Substructure:
```
Input (x)
↓
Multi-Head Self-Attention
↓
LayerNorm(x + Sublayer(x))
↓
Feed Forward Network
↓
LayerNorm(x + Sublayer(x))

```
---

---

## 4. Important Clarification

- **N = 6** means there are **6 identical encoder blocks stacked**
- It does NOT mean:
  - Layer 1 = Self-Attention
  - Layer 2 = Feed Forward

Instead:

> Each of the 6 blocks contains both sublayers.

---

## 5. Why Stack Multiple Layers?

Stacking layers allows the model to progressively refine its understanding.

You can think of it as multiple passes over the same sentence:

- Pass 1: Basic structure
- Pass 2: Relationships between words
- Pass 3: Context understanding
- Pass 4: Deeper dependencies
- Pass 5: Subtle patterns
- Pass 6: Final refined representation

Each layer builds on the previous one.

---

## 6. Residual Connections

Each sublayer uses a residual connection:

\[
\text{Output} = x + \text{Sublayer}(x)
\]

### Purpose:

- Prevents loss of original information
- Helps gradients flow during training
- Enables deeper networks without degradation

### Intuition:

Instead of replacing the input, the model **adds new information on top of it**.

---

## 7. Layer Normalization

After each residual addition, layer normalization is applied:

\[
\text{LayerNorm}(x + \text{Sublayer}(x))
\]

### Purpose:

- Stabilizes training
- Keeps values within a consistent range
- Ensures each layer receives well-conditioned inputs

The sequence is always:

> Add → Normalize

---

## 8. Model Dimension (d_model = 512)

All vectors in the encoder have the same dimensionality:

\[
d_{\text{model}} = 512
\]

This includes:

- Input embeddings
- Attention outputs
- Feed-forward outputs

### Why is this important?

Residual connections require:

\[
x + \text{Sublayer}(x)
\]

For this addition to work:

> Both terms must have the same dimensionality.

This enforces a consistent representation space throughout the model.

---

## 9. Final Summary

- The encoder consists of **6 identical stacked blocks**
- Each block contains:
  - Multi-head self-attention
  - Feed-forward network
- Each sublayer uses:
  - Residual connection
  - Layer normalization
- All representations maintain a fixed dimension of **512**

---

## 10. One-Line Summary

Six identical encoder blocks progressively refine the input representation using attention and feed-forward layers, while residual connections preserve information and layer normalization ensures stability.

# The Three Uses of Attention in the Transformer

## Overview

The Transformer uses attention in three distinct ways, each serving a different purpose in the translation pipeline. A useful mental model is to think of the architecture as an office building with two floors:

- **Encoder floor** — the research team: reads and builds a complete understanding of the input
- **Decoder floor** — the writing team: generates the output one token at a time

---

## Use 1: Encoder-Decoder Cross-Attention

```
Q  ←  comes from the DECODER (previous decoder layer)
K  ←  comes from the ENCODER output
V  ←  comes from the ENCODER output
```

This is the bridge between the two floors. The decoder's queries ask: "what part of the input do I need right now?" The encoder's keys and values provide the answers.

Every decoder position can attend freely to every encoder position — there is no masking here.

**Example — translating "I am happy" to "मैं खुश हूँ":**

```
Generating "मैं":
  Q = decoder state ("what do I need?")
  K = encoder output for ["I"(512), "am"(512), "happy"(512)]
  V = encoder output for ["I"(512), "am"(512), "happy"(512)]
  → attends most to "I"     → generates "मैं"

Generating "खुश":
  Q = decoder state (after generating "मैं")
  K = same encoder output (unchanged throughout)
  V = same encoder output
  → attends most to "happy" → generates "खुश"
```

The encoder output is fixed once computed. The decoder revisits it at every generation step, attending to whichever source positions are most relevant for the current output token.

---

## Use 2: Encoder Self-Attention

```
Q  ←  comes from the ENCODER (previous encoder layer)
K  ←  comes from the ENCODER (previous encoder layer)
V  ←  comes from the ENCODER (previous encoder layer)
```

All three come from the same place — the encoder attending to itself. This is the research team discussing the input among themselves before handing their notes to the writing team.

There is no masking. Every word can attend to every other word in the input freely, in both directions — past and future positions are all visible simultaneously.

**Example — "The animal didn't cross the street because it was too tired":**

```
"it"     → attends to: animal(0.65), tired(0.20), street(0.10), ...
"animal" → attends to: cross(0.40), street(0.30), didn't(0.20), ...
"tired"  → attends to: animal(0.55), it(0.30), because(0.15), ...
```

By the time the encoder finishes, each word's representation has absorbed context from the entire sentence. This rich, bidirectional understanding is what gets passed to the decoder.

## Feed-Forward Network (FFN)

Each encoder block contains a position-wise Feed-Forward Network applied after self-attention.

### Formula

$$\text{FFN}(x) = \max(0, xW_1 + b_1)W_2 + b_2$$

### How It Works

For each token:

1. **Expand representation:**
   - $512 \rightarrow 2048$

2. **Apply ReLU:**
   - Remove negative values

3. **Compress back:**
   - $2048 \rightarrow 512$


### Key Properties

- Applied independently to each position  
- Same weights shared across all tokens in the layer  
- Different weights across different layers  

### Role in Encoder

- Self-attention builds relationships between words  
- FFN processes each word’s representation deeply  

These two steps repeat across all encoder layers.
